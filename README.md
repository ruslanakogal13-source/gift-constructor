Gift Desingner  
Gift Desingner- це зручна лендінг-пейдж , для швидкого вибору подарунків за 
критеріями. 
Призначення проєкту 
Проєкт допомагає користувачу швидко і без довгих пошуків обрати подарунок, 
зберігти його. Усі  збережені ідеї автоматично записуються в пам'ять вашого браузера 
(localStorage) 
Головні можливості  -Пошук подарунка за вказаними критеріями  -Функція обрати подарунок за хоббі людини  -Зберігати подарунки які сподабалися  -Підбірка магазинів де можна купити рекомендовані подарунки

Доступні модулі 
Модуль                                                                                                 
 призначення  
Index.html- Головна сторінка: каркас лендінгу, секції, форма   підбору та контейнери 
для виведення подарунків. 
Style.css-Візуальне оформлення: стилі, кольорова гама, сітки, шрифти та адаптивність 
для мобільних пристроїв. 
Script.js-Логіка сайту: генерація ідей подарунків, фільтрація магазинів, робота з 
формами та збереження обраного в localStorage. 
Системні вимоги  
-Будь-який сучасний веббраузер (Google Chrome, Mozilla Firefox, Safari, Microsoft 
Edge). - Увімкнений JavaScript у браузері (він потрібен для генератора подарунків та 
збереження в обране через localStorage). -Підключення до інтернету (для завантаження шрифтів та переходу на сайти 
магазинів з розділу «Де купити»). 
Встановлення та запуск  
1. Завантажте або склонуйте проєкт на свій комп'ютер. 
2. Переконайтеся, що всі три файли (index.html, style.css, script.js) знаходяться в 
одній папці. 
3. Двічі клацніть лівою кнопкою миші на файл index.html, щоб відкрити його у 
своєму браузері.
